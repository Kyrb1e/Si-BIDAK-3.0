Cara membuat database (PGN Builder)

Jalankan di komputer Anda, lalu muat output/gm_games.pgn ke kartu ini. Data disimpan di browser dan tidak diunggah ke mana pun.

pip install python-chess requests beautifulsoup4 zstandard
# Kecil (uji coba)
python chessreps_builder.py --twic-range 1640 1664 --merge --gm --min-elo 2600 --max-games 20000
# Sedang
python chessreps_builder.py --twic-range 1500 1664 --broadcast-range 2024-01 2026-09 --merge --gm --min-elo 2500 --since 2015 --max-games 100000
# Statistik offline tertanam di file HTML
python chessreps_builder.py --stats --embed index.html

Builder sengaja berupa skrip, bukan berisi jutaan PGN, supaya ukuran database bisa Anda tentukan sendiri lewat --min-elo, --since, dan --max-games. File broadcast .pgn.zst berukuran besar dan hasil dekompresinya jauh lebih besar.
